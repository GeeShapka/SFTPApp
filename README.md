<h1>Goals for this project</h1>
<ul>
  <li>Ability to select files or folders on a local machine to transfer to a remote machine</li>
  <li>Ability to select files or folders on a remote machine to transfer to a local machine</li>
  <li>Support for Linux and Windows remote machines</li>
</ul>
